# Dxlian 的桌宠合集 · Petdex Pets

15 只会动的小伙伴，来自 [@dxlian 的 Petdex 主页](https://petdex.dev/u/dxlian)。

收录《凡人修仙传》角色、银月的不同形态，以及 erdu、caicai、CC Cat 和 gulu。每只保留完整的 `pet.json` 与透明背景精灵图，可离线保存、安装到支持该格式的 Codex 桌面客户端。

**15 只桌宠 · 动态预览 · 原始素材 · 批量安装 · SHA-256 校验**

This collection archives all 15 pets published by **dxlian** on Petdex as of **2026-10-27**, with animated previews, original sprite sheets, and a dependency-free Python installer. Browse the gallery below or download the entire repository as a ZIP.

## 下载与安装

**下载整个合集：** [Download ZIP](https://github.com/dxlian/petdex-pets/archive/refs/heads/main.zip)，或运行：

```sh
git clone https://github.com/dxlian/petdex-pets.git
cd petdex-pets
```

### 安装到 Codex

解压 ZIP 后进入仓库目录。需要 Python 3.9 或更高版本，无需安装第三方库。

```sh
# 检查文件完整性
python scripts/validate.py

# 先预览安装内容
python scripts/install.py --dry-run

# 安装全部 15 只
python scripts/install.py

# 也可只安装指定桌宠（--pet 可重复）
python scripts/install.py --pet erdu --pet hanli-2
```

Windows 可将 `python` 替换为 `py -3`；macOS / Linux 通常使用 `python3`。

默认复制到 `~/.codex/pets/<原始 id>/`；如果设置了 `CODEX_HOME`，则使用该目录下的 `pets/`。也可用 `--dest <目录>` 指定目标。安装器先校验文件，再复制；相同文件会跳过，遇到已有不同版本会报告冲突并保留原文件。它不会联网下载，也不会自动修改当前选中的桌宠。

安装后重新打开支持自定义桌宠的 Codex 客户端，在桌宠选择界面查看。也可以手动将某只桌宠的两个文件复制到 `~/.codex/pets/<id>/`，其中 `<id>` 见下表。

### 通过 Petdex 安装

如果使用 Petdex 桌面端，可打开每只桌宠的页面，按网站提供的方式安装，或使用官方 CLI：

```sh
npx petdex install erdu
```

这是 Petdex 自己的安装流程，目录和客户端行为以 [官方文档](https://petdex.dev/docs) 为准。上面的离线 Python 安装器针对 Codex 的自定义桌宠目录。

## 文件与版本

```text
pets/<slug>/pet.json          桌宠名称、说明与原始 id
pets/<slug>/spritesheet.webp  原始透明精灵图，1536 × 1872
previews/<slug>.gif           动态预览
catalog.json                 名录、来源链接、版本、字节数与 SHA-256
scripts/install.py           离线安装器
scripts/validate.py          完整性检查
```

本次整理以 **2026-10-27 的 Petdex 作者主页上全部 15 只已发布桌宠**为范围。14 张图片与本地保存版本逐字节一致；玄骨采用 Petdex 已发布版本，以保证合集与网站对应。未发布草稿、别名副本、旧备份不在合集范围内。

银月狐狸的两个版本具有不同的原始 id 和图像，因此分别保留。安装素材未经重绘或重新压缩；GIF 仅用于展示。所有来源和文件校验值见 [catalog.json](catalog.json)。
