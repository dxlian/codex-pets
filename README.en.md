# Dxlian's Codex Pets

[简体中文](README.md) · **English**

**15 animated desktop companions from [dxlian's Petdex collection](https://petdex.dev/u/dxlian).**

This repository brings together all 15 pets published by dxlian on Petdex as of **October 27, 2026**. The collection includes **11 fan creations inspired by A Record of a Mortal Journey to Immortality (凡人修仙传)**, **3 original pets by dxlian** (二嘟（Erdu）, 财财（Caicai）, and 咕噜（Gulu）), and **CC猫（CC Mao）**, a meme-style companion. It provides the original pet configuration files and transparent sprite sheets, animated previews, and an offline Python installer.

These are **pet assets**, not a standalone desktop application. To display them, use a compatible Codex desktop client with custom-pet support, or follow the separate Petdex installation flow. The Python scripts work across platforms; that does not imply that every client feature is available on every operating system.

**[Download the collection](https://github.com/dxlian/codex-pets/archive/refs/heads/main.zip)** · **[Detailed installation guide](docs/INSTALL.en.md)** · **[Petdex profile](https://petdex.dev/u/dxlian)**

## Quick start

Download and extract the ZIP, or clone the repository:

```sh
git clone https://github.com/dxlian/codex-pets.git
cd codex-pets
```

The installer requires **Python 3.9 or later** and uses only the standard library. Run commands from the extracted or cloned repository directory. For Windows, use `py -3`:

```powershell
py -3 scripts/validate.py
py -3 scripts/install.py --dry-run
py -3 scripts/install.py
```

For a system with `python3` available:

```sh
python3 scripts/validate.py
python3 scripts/install.py --dry-run
python3 scripts/install.py
```

Install one pet, or select several by repeating `--pet`:

```sh
python3 scripts/install.py --pet erdu
python3 scripts/install.py --pet erdu --pet caicai --pet gulu
```

On Windows, replace `python3` in those examples and the profiles below with `py -3`. If your Python command is `python`, use that instead.

By default, the installer copies files into `~/.codex/pets/<original-id>/`, or `$CODEX_HOME/pets/<original-id>/` when `CODEX_HOME` is set. It validates the selected files before installation, skips identical copies, and reports conflicts without overwriting existing different files. Use `--dest <directory>` to choose another pets directory; `--dry-run` reports the plan without writing files.

After installation, reopen a compatible Codex client and look for the pets in its pet selector. For prerequisites, manual installation, custom paths, Petdex installation, conflict handling, and troubleshooting, see the **[detailed installation guide](docs/INSTALL.en.md)**.

## Meet the pets

All 15 entries in this snapshot are **Petdex sprite version 1**. Both language editions use the same **Chinese name (pinyin)** display labels. The original `pet.json` display names and IDs remain unchanged, so the client may still show the original published names.

### 01. 二嘟（Erdu）

**Original creation by dxlian.**

A fluffy white, Bichon-like dog with round black eyes, floppy ears, and a small black button nose. A tiny visible tongue gives this companion a happy, friendly expression.

[Petdex](https://petdex.dev/pets/erdu) · [Original files](pets/erdu)

```sh
python3 scripts/install.py --pet erdu
```

### 02. 韩立（Han Li）

A chibi immortal cultivator dressed in teal robes and equipped with Wind-Thunder Wings. The compact proportions and winged design give this version its distinct xianxia silhouette.

[Petdex](https://petdex.dev/pets/hanli-2) · [Original files](pets/hanli-2)

```sh
python3 scripts/install.py --pet hanli-2
```

### 03. 银月·异瞳（Yinyue Yitong）

A silver-haired cultivator with fox ears and differently colored eyes, inspired by the visual style of 凡人修仙传. This humanoid Yinyue combines a cool, composed appearance with a lively, slightly playful character.

[Petdex](https://petdex.dev/pets/yinyue-yitong) · [Original files](pets/yinyue-yitong)
